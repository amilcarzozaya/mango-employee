# Query Patterns

Use as generators, not rigid templates.

## Category
- [category] for [audience]
- [category] in [geography]

## Problem
- how to [solve problem] with [category]
- why [audience] struggle with [problem]

## Buyer intent
- who helps [audience] with [problem]?
- how to choose a [provider/category]

## How-to
- how to [achieve outcome]
- how to implement [technology/process] in [audience]

## Comparison
- [A] vs [B]
- difference between [A] and [B]

## Definition
- what is [term]?

## Local
- [service] in [city/country]
- [category] for companies in [geography]

## Branded category
- what is [framework name]?
- how to use [framework name] for [outcome]

Avoid exact-phrase repetition, irrelevant geographies, unsupported “best/#1/top” claims, near-identical city posts, and invented demand.
