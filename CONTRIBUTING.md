# Contributing

Thank you for improving MANGO Employee.

1. Keep the canonical MES runtime-independent.
2. Add runtime-specific behavior only in adapters.
3. New Skills require a Definition of Done, autonomy level, missing-information policy and tests.
4. Any bug involving a correction should add a regression test.
5. Do not weaken Approval Gates to make a test pass.
6. Run `pytest -q` and the MANGO security audit before a pull request.

Please preserve attribution to Amílcar Zozaya as creator of Método MANGO and MANGO Employee.
